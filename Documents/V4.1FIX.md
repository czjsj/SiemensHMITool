请实现以下函数：

1. normalize_legacy_tag_bindings(ir: dict) -> dict

功能：

- 遍历 ir["objects"]。

- 对 Button / Indicator / IOField / SymbolicIOField 自动推断变量名。

- 如果对象已有 process_tag，则以 process_tag 为准。

- 如果没有 process_tag 但有 tag_binding，则使用 tag_binding。

- 如果没有上述两个，但 binding.tag 存在，则使用 binding.tag。

- 如果三个都不存在，则根据对象类型和名称自动生成变量名。

- 最终必须写回：
  obj["process_tag"]
  obj["tag_binding"]
  obj["binding"]["tag"]

- 同时保证 ir["tags"] 中存在该变量。

- 如果 ir["tags"] 中没有该变量，则自动新增 tag spec。

- 如果同名变量数据类型冲突，则抛出错误或返回 blocking diagnostic。
2. infer_tag_name_from_object(obj: dict) -> str

命名规则：

- Button 瞬时按钮：BTN_*
- Button 自保持 / toggle：MEM_*
- Indicator 普通状态：STS_*
- Indicator 故障 / 报警：LMP_*
- IOField：IO_*
- SymbolicIOField：SIO_*

中文/特殊字符需要转为安全变量名。
例如：

- “启动按钮” → BTN_Start 或 BTN_QiDong，使用项目已有命名工具优先。

- 不要生成空变量名。

- 不要生成带空格、中文标点、非法 XML 字符的变量名。
3. infer_legacy_tag_spec(obj: dict, tag_name: str) -> dict

默认数据类型：

- Button：Bool
- Indicator：Bool
- IOField：Real，除非 obj.data_type / format 指定 Int / DInt / Real
- SymbolicIOField：Int
- 其他：Bool

返回结构至少包含：
{
  "name": tag_name,
  "data_type": "...",
  "address": "",
  "comment": "Auto generated for ..."
}

4. assert_legacy_tags_complete(ir: dict) -> None

要求：

- 每个需要变量的控件必须有 process_tag/tag_binding/binding.tag。
- 三者必须一致。
- 绑定变量必须存在于 ir["tags"]。
- 否则 raise ValueError，错误信息里列出 object id/name/type/tag/reason。

伪代码参考：

CONTROL_TYPES_REQUIRING_TAG = {
    "Button",
    "Indicator",
    "IOField",
    "SymbolicIOField",
}

def normalize_legacy_tag_bindings(ir: dict) -> dict:
    ir = copy.deepcopy(ir)
    objects = ir.setdefault("objects", [])
    tags = ir.setdefault("tags", [])

    tag_map = {}
    for tag in tags:
        if isinstance(tag, dict) and tag.get("name"):
            tag_map[tag["name"]] = tag
    
    for obj in objects:
        if obj.get("type") not in CONTROL_TYPES_REQUIRING_TAG:
            continue
    
        tag_name = (
            obj.get("process_tag")
            or obj.get("tag_binding")
            or ((obj.get("binding") or {}).get("tag"))
        )
    
        if not tag_name:
            tag_name = infer_tag_name_from_object(obj)
    
        obj["process_tag"] = tag_name
        obj["tag_binding"] = tag_name
        obj.setdefault("binding", {})
        obj["binding"]["tag"] = tag_name
    
        if tag_name not in tag_map:
            tag_spec = infer_legacy_tag_spec(obj, tag_name)
            tags.append(tag_spec)
            tag_map[tag_name] = tag_spec
    
    assert_legacy_tags_complete(ir)
    return ir

def _execute_import_tags(self, step, context):
    tags_xml = step.payload["tags_xml"]
    expected = set(step.payload["tag_names"])

    xml_path = self._write_temp_xml(tags_xml, suffix="_hmi_tags.xml")
    result = self._import_hmi_tag_xml(context.hmi_software, xml_path)
    
    actual = set(self._query_hmi_tag_names(context.hmi_software))
    missing = sorted(expected - actual)
    
    if missing:
        return ClassicStepResult(
            ok=False,
            phase=step.phase,
            message=f"HMI tag import incomplete. Missing tags: {missing}",
            diagnostics=[...],
            payload={
                "expected_count": len(expected),
                "actual_count": len(actual),
                "missing_tags": missing,
            },
        )
    
    return ClassicStepResult(
        ok=True,
        phase=step.phase,
        message=f"Imported {len(expected)} HMI tags",
        payload={
            "imported_count": len(expected),
            "tag_names": sorted(expected),
        },
    )

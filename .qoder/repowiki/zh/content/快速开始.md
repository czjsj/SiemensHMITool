## 简介

Siemens HMI Assistant 是一个基于人工智能的西门子 HMI 画面生成平台，能够通过自然语言描述自动生成 HMI 控制画面，并支持与博途（TIA Portal）的无缝集成。该平台提供了完整的开发周期支持，从需求描述到最终的 HMI 画面部署。

平台的核心特性包括：
- **自然语言生成**：通过中文描述生成标准化的 HMI 画面 IR（中间表示）
- **多模型支持**：支持 DeepSeek、OpenAI 等多家大模型提供商
- **视觉审查**：集成 MiMo-V2.5 进行多阶段视觉质量审查
- **模板驱动**：支持经典 HMI 模板和 Unified 直接绘制两种生成模式
- **博途集成**：提供完整的 Openness API 集成，支持 XML 导入和实时预览

## 系统要求

### 硬件要求
- **CPU**：Intel Core i5 或同等性能的 AMD 处理器
- **内存**：至少 8GB RAM（推荐 16GB+）
- **存储**：至少 5GB 可用磁盘空间
- **网络**：稳定的互联网连接（用于大模型 API 访问）

### 软件要求

#### Python 环境
- **Python 版本**：3.10 - 3.12（强烈推荐 3.10.14）
- **操作系统**：Windows 10/11（推荐），Linux/macOS 可用但部分功能受限

#### 依赖包
根据 requirements.txt 文件，主要依赖包括：
- **Flask >= 3.0.0**：Web 应用框架
- **PyYAML >= 6.0**：配置文件处理
- **requests >= 2.31.0**：HTTP 请求处理
- **pdfplumber >= 0.10.0**：PDF 文本提取
- **Pillow >= 10.0.0**：图像处理
- **pythonnet >= 3.0.3**：Windows 平台博途集成（可选）

#### 博途环境（可选）
- **TIA Portal**：支持 V16/V18/V20 版本
- **Siemens Engineering DLL**：用于 Openness API 集成
- **HMI 设备**：支持 Basic/Comfort/Unified 类型

## 安装步骤

### 步骤 1：准备 Python 环境

1. **下载并安装 Python 3.10.14**
   - 访问 [python.org](https://www.python.org/downloads/release/python-31014/)
   - 下载适合您系统的安装包
   - 安装时勾选"Add to PATH"选项

2. **验证 Python 安装**
   ```bash
   python --version
   pip --version
   ```

### 步骤 2：克隆或下载项目

```bash
# 克隆仓库
git clone https://github.com/your-repo/SiemensHmi_Assistant.git
cd SiemensHmi_Assistant

# 或者下载 ZIP 文件并解压
```

### 步骤 3：创建虚拟环境（推荐）

```bash
# 创建虚拟环境
python -m venv .venv

# 激活虚拟环境
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate
```

### 步骤 4：安装依赖包

```bash
# 升级 pip
python -m pip install --upgrade pip

# 安装项目依赖
pip install -r requirements.txt
```

**注意**：如果遇到安装问题，可以尝试以下替代方案：
```bash
# 使用国内镜像源
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple/

# 或者跳过特定包的安装
pip install Flask PyYAML requests pdfplumber Pillow
```

### 步骤 5：验证安装

```bash
# 检查所有依赖是否正确安装
pip list | grep -E "(flask|pyyaml|requests|pdfplumber|pillow)"
```

## 环境配置

### 配置文件位置

项目使用 YAML 格式的配置文件 `config.yaml`，位于项目根目录。首次运行时会自动生成默认配置。

### 基本配置项

#### LLM（大语言模型）配置
```yaml
llm:
  active_provider: deepseek          # 当前使用的模型提供商
  thinking_depth: 中                   # 思考深度：关闭/低/中/高
  stream: true                       # 是否启用流式输出
  show_thinking: true                # 是否显示思考过程
  providers:
    deepseek:
      base_url: https://api.deepseek.com
      api_key: sk-f0cb4ab3cf524b428a55124c91776ae5
      chat_model: deepseek-v4-pro
      reasoner_model: deepseek-reasoner
      supports_vision: false
    openai_compatible:
      base_url: https://api.openai.com/v1
      api_key: ''
      chat_model: gpt-4o-mini
      reasoner_model: o1-mini
      supports_vision: true
```

#### Openness（博途集成）配置
```yaml
openness:
  tia_version: V16                    # TIA Portal 版本
  dll_path: "C:\\Program Files\\Siemens\\Automation\\Portal V16\\PublicAPI\\V16\\Siemens.Engineering.dll"
  attach_running: true               # 是否附加到已运行的博途实例
  hmi_device: HMI_1                  # 目标 HMI 设备名
  generation_mode: auto              # 生成模式：auto/unified_direct/classic_template_xml/simaticml
  classic_template:
    enabled: true                    # 是否启用经典模板模式
    template_xml_path: "exports/templates/画面_1_template.xml"
  unified_direct:
    enabled: true                    # 是否启用 Unified 直接绘制
    update_existing_screen: true   # 是否更新现有画面
```

#### HMI 默认设置
```yaml
hmi_defaults:
  resolution: 800x480               # HMI 分辨率
  hmi_type: Basic                   # HMI 类型：Basic/Comfort/Unified
  background_color: '#D9DEE5'       # 背景色
  font_family: Arial                # 字体
```

#### 输出配置
```yaml
output:
  export_dir: exports               # 导出目录
  encoding: utf-8-sig              # 文件编码
```

## 常见问题解决

### 问题 1：依赖安装失败

**症状**：pip 安装过程中出现错误

**解决方案**：
```bash
# 清理 pip 缓存
pip cache purge

# 使用国内镜像源
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple/

# 升级 setuptools 和 wheel
python -m pip install --upgrade setuptools wheel
```

### 问题 2：pythonnet 安装失败

**症状**：在非 Windows 系统上安装 pythonnet 失败

**解决方案**：
- 这是预期行为，pythonnet 仅在 Windows 上需要
- 应用会自动降级到诊断模式
- 可以在 Mac/Linux 上调试前端和大模型流程

### 问题 3：端口被占用

**症状**：启动时提示端口 5000 已被占用

**解决方案**：
```bash
# 修改 config.yaml 中的端口
server:
  host: 127.0.0.1
  port: 5001  # 更改为其他端口
  debug: true
```

### 问题 4：API Key 配置错误

**症状**：生成画面时报错"未配置 API Key"

**解决方案**：
1. 在 Web 界面右上角点击设置图标
2. 选择模型提供商
3. 填写正确的 API Key
4. 点击"测试连接"验证

### 问题 5：博途连接失败

**症状**：点击连接按钮无响应或报错

**解决方案**：
```yaml
# 检查 config.yaml 中的 DLL 路径
openness:
  dll_path: "C:\\Program Files\\Siemens\\Automation\\Portal V16\\PublicAPI\\V16\\Siemens.Engineering.dll"
  attach_running: true
  tia_version: V16
```
